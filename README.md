## GitHub Pages
Upload `index.html` to a repository such as `cest-israel`, then enable GitHub Pages from:
Settings → Pages → Deploy from branch → main → /(root).

The resulting project-site URL will normally look like:
https://YOUR-GITHUB-USERNAME.github.io/cest-israel/

Replace the placeholder service text and add your own images/content when ready.
